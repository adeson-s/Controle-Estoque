# AlmoxApp

Sistema inteligente de controle de almoxarifado para equipes de campo, desenvolvido para empresas que precisam controlar materiais, movimentações de estoque, consumo por técnico e gestão de múltiplas filiais.

## 🚀 Acesse a Demonstração

🌐 https://almoxapp.vercel.app

> Modo Demo disponível para testes.

---

## 📦 Sobre o Projeto

O AlmoxApp foi criado para resolver um problema comum em operações de campo: a falta de controle sobre materiais retirados pelos técnicos.

A plataforma centraliza o estoque de diversas filiais, registra movimentações em tempo real e fornece indicadores para tomada de decisão.

Ideal para empresas de:

* Telecomunicações
* Provedores de Internet
* Energia
* Manutenção Predial
* Equipes Técnicas Externas
* Operações Logísticas

## ✨ Principais Funcionalidades

### 📊 Dashboard Gerencial

* Indicadores de estoque
* Produtos críticos
* Ranking de perdas
* Tendência de consumo
* Gráficos analíticos

### 📦 Gestão de Produtos

* Cadastro de materiais
* Controle de estoque mínimo
* Histórico de movimentações
* QR Code individual por item
* Alertas automáticos de reposição

### 👷 Gestão de Técnicos

* Cadastro de técnicos
* Histórico individual
* Consumo por colaborador
* Controle por placa do veículo

### 🚚 Controle de Saídas

* Retirada de materiais
* Carrinho de produtos
* Observações por movimentação
* Registro de responsável
* Histórico completo

### 📋 Conferência de Estoque

* Inventário físico
* Comparação sistema x físico
* Identificação de divergências
* Conferência por filial

### 🏢 Multi-Filial

* Controle independente por unidade
* Permissões por filial
* Estoques separados

### 🔐 Controle de Acesso

Perfis de acesso:

* Gerente
* Supervisor
* Auxiliar
